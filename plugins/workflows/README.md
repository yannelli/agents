# Workflows

Reusable execution directives for the `yannelli-agents` marketplace.

## Contents

- **`skills/scoped-task-execution/`** — a skill that executes an individual issue or ticket as a tightly scoped task: smallest correct change, no scope creep. Invoke explicitly with `/workflows:scoped-task-execution`, or let Claude trigger it when you hand it a well-defined ticket.

## Install

```
/plugin install workflows@yannelli-agents
```
