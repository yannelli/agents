# Starter

Example plugin for the `yannelli-agents` marketplace. Copy this directory to bootstrap a new plugin.

## Contents

- **`skills/commit-message/`** — a skill that writes a commit message for staged changes. Invoke explicitly with `/starter:commit-message`, or let Claude trigger it when you ask for a commit message.
- **`agents/code-explainer.md`** — a read-only subagent that walks through how a piece of code works.

## Install

```
/plugin install starter@yannelli-agents
```
